# Academic Phrases to Remove or Replace

## Vague Significance Inflation

These phrases announce importance without naming what is important. Replace each with the specific thing.

| Avoid | Replace with |
|-------|-------------|
| "significant implications" | Name the implication: "reduces false-negative rates by 40%" |
| "far-reaching consequences" | Name the consequence: "increases ICU length of stay by 3.2 days" |
| "critical gap in the literature" | Name the gap: "No prior study has validated AKI prediction models on non-US ICU cohorts" |
| "the stakes are high" | Name the stakes: "AKI mortality exceeds 50% in untreated Stage 3 cases" |
| "the consequences are real" | Name the consequences: "Each hour of delayed AKI detection increases 30-day mortality by 2%" |
| "this is a pressing concern" | Provide the evidence: "AKI incidence has risen 2.5% annually over the past decade" |
| "not to be underestimated" | State the magnitude with data |
| "of paramount importance" | State what it is important for, specifically |
| "cannot be overstated" | Remove entirely. State the fact. |
| "deserves careful attention" | Name what should be done and why |

## Hedging Abuse

These phrases create uncertainty without adding information. Either commit to the claim with evidence, or state explicit uncertainty bounds.

| Avoid | Replace with |
|-------|-------------|
| "may potentially" | "may" alone, or cite the probability |
| "could possibly" | "could" alone, or cite the mechanism |
| "it is suggested that" | "Evidence suggests" + cite the evidence |
| "it might be the case that" | State the claim directly |
| "there is reason to believe" | "Evidence shows" + cite it |
| "would seem to indicate" | "indicates" or "suggests" |
| "it appears that" | Use when you genuinely lack certainty, but prefer "X shows that Y" |
| "one could argue that" | Name who argues it: "Smith et al. argue that..." |
| "it is conceivable that" | Delete unless followed by a specific mechanism |
| "this may in part explain" | "This explains" if you have evidence; "One possible explanation is" if speculative |

## Academic Throat-Clearing

These phrases delay the actual finding. State the finding directly.

| Avoid | Replace with |
|-------|-------------|
| "It is well established that" | State the finding with a citation |
| "Extensive research has shown" | Cite the 2 most relevant studies |
| "A growing body of literature suggests" | Cite the recent studies |
| "It has long been recognized that" | State the recognition with a founding citation |
| "There is broad consensus that" | Name the consensus source |
| "It is widely acknowledged that" | Name who acknowledges it |
| "Research in this area has demonstrated" | Cite the demonstration |
| "Scholars have consistently found" | Name the scholars |
| "The literature consistently shows" | Cite the literature |
| "As has been previously reported" | Cite the previous report |

## Metaphor Abuse in Science

Replace vague metaphors with precise technical language.

| Avoid | Replace with |
|-------|-------------|
| "bridges the gap" | "connects X to Y" or "integrates X with Y" |
| "paves the way for" | "enables" or "makes possible" |
| "landscape" (as in "the current landscape") | "the current state of" or "existing" |
| "paradigm shift" | "change in approach" or name the specific change |
| "shed light on" | "elucidates" or "explains" |
| "underscores the importance of" | "shows that X matters because Y" |
| "paints a compelling picture" | "demonstrates" |
| "opens new avenues" | "enables further investigation into X" |
| "cuts across disciplines" | "integrates methods from X and Y" |
| "a rich tapestry of" | Delete. Name the components. |
| "at the intersection of" | "combining X and Y" or "at the boundary of" |
| "holistic approach" | "comprehensive approach" or name what is included |
| "leverages" | "uses" or "applies" |

## Methodology Theater

Standard procedures do not need elaborate justification. Strip to essentials.

| Avoid | Replace with |
|-------|-------------|
| Elaborate justification for k-fold CV | "We used 10-fold cross-validation." |
| Explaining what SHAP is | "We computed SHAP values for feature attribution." (Cite Lundberg & Lee) |
| Describing why train-test splits exist | "We split data 70/15/15 for training, validation, and testing." |
| Defining common metrics (AUC-ROC) | "We report AUC-ROC, AUPRC, and Brier score." |
| Justifying the use of deep learning | State what architecture you use and why for this specific problem |
| Explaining what a transformer is | "We use a Transformer encoder with X attention heads." |

## Filler Transitions

These connective words add no logical content between unrelated points.

| Avoid | Use instead |
|-------|-------------|
| "Furthermore," (between unrelated points) | Start a new paragraph, or restructure to show the relationship |
| "Moreover," (padding) | Cut. If the point follows, it follows without announcement. |
| "Additionally," (listing weakly related items) | Restructure into a proper list or separate paragraph |
| "It should also be noted that" | State the note directly |
| "It is worth mentioning that" | State it |
| "Notably," (before a routine point) | Cut unless the point is genuinely surprising |
| "Importantly," (before any claim) | Cut. Let the claim's importance speak through its content |

## Overstatement of Novelty

These words require verifiable evidence that no prior work exists.

| Avoid | Use instead |
|-------|-------------|
| "novel" (without evidence) | "proposed" or "developed"; add "To our knowledge, no prior study..." with evidence |
| "innovative" | Describe what is different and why it matters |
| "first-of-its-kind" | "the first study to [specific thing]" — only if verified |
| "groundbreaking" | Delete. Let reviewers decide |
| "pioneering" | Delete. Same reason. |
| "unprecedented" | Name what is unprecedented and verify it |
| "revolutionary" | Delete. Never use this in a proposal. |

## Redundant Academic Pairs

These word pairs say the same thing twice.

| Avoid | Use |
|-------|-----|
| "future prospects" | "prospects" |
| "past history" | "history" |
| "basic fundamentals" | "fundamentals" |
| "end result" | "result" |
| "final outcome" | "outcome" |
| "mutual cooperation" | "cooperation" |
| "brief summary" | "summary" |
| "completely eliminate" | "eliminate" |
| "closely monitor" | "monitor" |
| "carefully examine" | "examine" |
